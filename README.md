# Week 1 - Basic Algorithms

This folder contains implementations of fundamental algorithms covered in Week 1 of the ADA lab.

## 📌 Programs Included

* Binary String Generation
* Linear Search
* Missing Number
* Sum of Arrays
* Tower of Hanoi
* Power Calculation (Iterative & Recursive)
* Permutations

## 🎯 Objective

To understand basic problem-solving techniques using recursion, iteration, and simple logic building.

## 💡 Learning Outcomes

* Improved understanding of recursion
* Hands-on practice with basic algorithms
* Visualization of algorithm behavior using Python graphs
